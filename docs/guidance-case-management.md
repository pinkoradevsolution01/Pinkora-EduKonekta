# Guidance case management

Cases are created from a confidential safety report by an active safeguarding-authorized guidance user. The creator receives an elevated assignment. Other staff must be explicitly assigned and hold active safeguarding access; school administrators have no automatic access. Views, changes, notes, exports, and assignments are audited. Closed cases preserve notes and can be reopened only by an elevated assignee. Exports require elevated assignment. General analytics must use de-identified aggregates only; this module exposes no general-school case listing endpoint.
