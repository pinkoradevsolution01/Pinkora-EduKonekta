# Whole-system validation matrix

**Scope:** local demo environment, validated 2026-08-04.  
**Status labels:** **Pass (local)** means automated/local evidence exists; **Partial** means code controls exist but production/pilot evidence is still required; **Open** means the validation has not yet been demonstrated. A Partial or Open row must not be represented as production approval.

| Area            | Required validation                                           | Current evidence                                                                                                                                        | Status                | Required pilot/production evidence                                                                              |
| --------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- | --------------------------------------------------------------------------------------------------------------- |
| Authentication  | Only verified, active school users can access the platform    | `auth.service.spec.ts`, rate-limit tests, login browser journey, secure cookie/session revocation checks                                                | Pass (local)          | Configure mail delivery for verification/recovery and repeat against production identity data                   |
| Multi-tenancy   | One school cannot access another school's data                | Tenant guard matrix, `tenant-query` tests, report-isolation tests, school-admin invitation test                                                         | Pass (local)          | Authenticated School A/School B negative test in staging/production                                             |
| Student access  | Students see only their records and assigned learning content | Assignment input rejects client-selected student ID; attendance/evaluation rules use authenticated student/active enrollment                            | Pass (local)          | Student pilot test with a second student negative check                                                         |
| Teacher access  | Teachers see only assigned classes and students               | Structure, attendance, assignment, and evaluation tests enforce teacher assignment                                                                      | Pass (local)          | Selected teacher performs assigned/unassigned class checks                                                      |
| Parent access   | Parents see only verified linked children                     | Parent dashboard, attendance, and evaluation tests require an approved parent-student link                                                              | Pass (local)          | Linked and unlinked parent account checks in pilot tenant                                                       |
| Guidance access | Sensitive cases require explicit authorization                | Safety/guidance service tests; active safeguarding access and explicit case assignment documented and enforced                                          | Pass (local)          | Guidance lead authorization review before enabling related feature flags                                        |

## Evidence commands

Run the local checks before updating a row to Pass (local):

```powershell
npm.cmd test --workspace=@pinkora/api
$env:PLAYWRIGHT_BASE_URL = 'http://localhost:3100'
npm.cmd run test:e2e
Remove-Item Env:PLAYWRIGHT_BASE_URL
powershell -ExecutionPolicy Bypass -File scripts/restore-test.ps1
powershell -ExecutionPolicy Bypass -File scripts/smoke-test.ps1
```

For a deployed environment, follow [deployment-runbook.md](deployment-runbook.md) and attach the output of the production smoke test, authenticated cross-tenant negative test, managed restore exercise, monitoring test alert, training records, and school approval. See [release-readiness-report.md](release-readiness-report.md) for the current release decision.
